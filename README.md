I lead internationalization efforts at [W3C](https://www.w3.org/), working to ensure the web works well for all languages, scripts, and cultures.

## Standards Work

**Unicode Consortium**
- Co-author of [UTR #59: East Asian Spacing](https://www.unicode.org/reports/tr59/) - defining spacing rules for CJK text layout

**W3C Internationalization**
- Editor of multiple [language enablement](https://www.w3.org/International/i18n-drafts/nav/languagedev) documents - requirements for supporting the world's writing systems on the web
- Contributor to i18n [articles](https://www.w3.org/International/articlelist) and [specdev guidelines](https://www.w3.org/TR/international-specs/)
- Staff Contact for the [Internationalization Working Group](https://www.w3.org/International/)

**CSS Working Group**
- Contributor to CSS Text and CSS Fonts

**Other W3C Work**
- Contributor to [MiniApps Working Group](https://www.w3.org/2021/miniapps/) specifications
